Milestone 9: Minimal Static Graph Context

AgentTelemetry now enriches static.json and reports with best-effort graph context from source parsing. The static pass does not execute user code and never blocks runtime testing.

Implementation

  • Added src/agenttelemetry/runtime/static_context.py.
  • Parses the entrypoint source with Python ast.
  • Detects exported entrypoint file and symbol from file.py:graph.
  • Extracts fixture nodes from builder.add_node and builder.set_entry_point.
  • Extracts edges from builder.add_edge and builder.add_conditional_edges.
  • Extracts tool inventory from tools.py and from tools import ....
  • Marks static data with best_effort=true and source limitations.
  • Keeps runtime CI execution alive if static parsing fails.

Report Changes

report.json already included static. It now receives real best-effort context instead of a placeholder. report.html also renders a Static Context section that identifies status, best-effort mode, entrypoint, nodes, and tools.
