Milestone 8: Stable Reports And CI Command

AgentTelemetry now completes the MVP CI loop: it runs the isolated LangGraph fixture, evaluates deterministic assertions, creates evidence-backed findings, writes a stable artifact directory, and exits according to a severity threshold.

Command agenttelemetry ci
Machine Report report.json
Human Report report.html
Fixture Exit 1

Implemented Loop

agenttelemetry ci file.py:graph --config tests.yaml --out-dir runs/customer-support
  -> write static.json placeholder
  -> run graph in isolated subprocess
  -> write trace.jsonl
  -> evaluate deterministic assertions
  -> write tests.json
  -> create high-severity finding
  -> write findings.json
  -> write report.json and report.html
  -> exit 1 when finding severity >= threshold

Files Changed

File Purpose
src/agenttelemetry/runtime/reports.py Adds report builders, static placeholder generation, trace summary, findings summary, standalone HTML rendering, severity threshold comparison, and report artifact writing.
src/agenttelemetry/cli.py Adds agenttelemetry ci, writes the full artifact layout, applies --severity-threshold, and returns exit code 1 for threshold-matching findings.
.github/workflows/ci.yml Runs the fixture CI loop, expects exit code 1, and uploads runs/customer-support/report.html.
tests/integration/test_isolated_runner.py Adds integration coverage for full artifact layout, report JSON content, standalone report HTML, severity threshold behavior, and invalid config report generation.
README.md Documents the new ci command and stable CI artifact layout.
