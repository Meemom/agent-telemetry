Milestone 7: Finding Creation

AgentTelemetry now converts a failed deterministic assertion into an evidence-backed security finding. This milestone keeps assertion failure separate from severity classification: assertions decide whether a test passed, while the risk map decides how serious the observed behavior is.

Primary Artifact findings.json
Built-In Risk send_email
Severity high
Confidence high

Implemented Loop

LangGraph app
  -> isolated run
  -> trace.jsonl
  -> failed tool_not_called assertion
  -> high-risk send_email classification
  -> evidence-backed SecurityFinding
  -> findings.json

What Was Added

  • A built-in tool risk map containing send_email as a high-risk external communication tool.
  • Structured finding creation from failed tool_not_called assertions that include runtime event evidence.
  • Stable assertion IDs so findings can reference the exact failed assertion that produced them.
  • Deterministic finding IDs based on test name, assertion ID, and tool name.
  • findings.json writing from agenttelemetry test.
  • Golden-file coverage for the customer-support fixture finding.

Files Changed

File Purpose
src/agenttelemetry/runtime/findings.py Adds ToolRisk, BUILT_IN_TOOL_RISKS, and create_findings. Converts failed assertion evidence into SecurityFinding objects.
src/agenttelemetry/model/finding.py Extends SecurityFinding with optional assertion_id, tool_category, and attempted_side_effect.
src/agenttelemetry/model/test.py Adds assertion_id to AssertionResult so findings can reference the failed assertion directly.
src/agenttelemetry/runtime/assertions.py Generates stable assertion IDs during deterministic assertion evaluation.
src/agenttelemetry/cli.py Calls create_findings, attaches findings to tests.json, and writes standalone findings.json.
examples/langgraph_apps/customer_support/expected/findings.json Defines the golden expected finding for the safe customer-support fixture, with runtime event ID normalized by the test.
tests/test_findings.py Unit tests the finding factory for high severity, high confidence, assertion reference, runtime evidence, tool category, attempted side effect, and remediation.
tests/integration/test_isolated_runner.py Verifies agenttelemetry test writes findings.json and matches the golden fixture.
