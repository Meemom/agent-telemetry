Milestone 5: Minimal Trace and Tool Attempt Capture

Milestone 5 added OpenTelemetry-compatible runtime trace data without adding the OpenTelemetry SDK yet. The local MVP writes JSONL events that downstream exporters can later map into OTLP spans.

Implemented Behavior

  • Generates one run_id through the run manifest.
  • Generates one 32-character trace_id per isolated run.
  • Generates 16-character span IDs for root and tool events.
  • Writes root span_start and span_end events.
  • Records duration_ms on the root span end event.
  • Captures simulated tool attempts as tool_call events.
  • Records tool name in attributes.agenttelemetry.tool_name.
  • Defaults to payload_mode=none, so raw tool arguments are absent from trace.jsonl.
  • Supports opt-in payload modes: none, summary, and full.
  • Supports redaction modes: strict, metadata, and off.

Milestone 6: Deterministic Assertion Engine

Milestone 6 added a deterministic test command that loads tests.yaml, validates the config, runs the graph through the isolated runner, evaluates assertions against trace evidence and output, then writes tests.json.

Implemented Behavior

  • Loads YAML test config through PyYAML.
  • Validates config using Pydantic models.
  • Implements tool_called and tool_not_called against tool_call trace events.
  • Implements regex_matches and regex_not_matches against either final output or captured trace tool arguments.
  • Writes deterministic tests.json.
  • Returns exit code 1 when a configured assertion fails.
  • Returns exit code 2 for invalid entrypoints or invalid test config.
  • Includes evidence event IDs on failed tool assertions.
