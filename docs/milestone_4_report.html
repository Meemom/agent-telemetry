Milestone 4: Isolated Entrypoint Runner

Implemented a safe subprocess runner for LangGraph entrypoints so AgentTelemetry can execute a user graph, enforce timeouts, suppress live tool access by default, and write reproducible run metadata.

Branch dev
Primary command agenttelemetry observe
Default safety mode Live tools disabled
Timeout exit code 124

What Changed

  1. Added entrypoint parsing for strings like examples/langgraph_apps/customer_support/app.py:graph.
  2. Added a subprocess worker that imports the graph from the target file and invokes its invoke method with JSON input.
  3. Added an isolated runner that starts the worker, passes JSON through stdin, enforces timeouts, and returns structured execution results.
  4. Added safe environment defaults: AGENTTELEMETRY_LIVE_TOOLS=0 unless the user passes --allow-live-tools.
  5. Added RunManifest so each run records schema version, CLI version, entrypoint, output directory, timestamps, redaction mode, payload mode, timeout, live-tool setting, and final exit code.
  6. Added agenttelemetry observe to run one entrypoint and write manifest.json plus output.json.
  7. Added unit and integration tests for parser behavior, success, timeout, invalid entrypoints, and manifest safety flags.

Files Implemented

File Purpose
src/agenttelemetry/model/manifest.py Defines RunManifest for reproducible run metadata and schema-versioned artifacts.
src/agenttelemetry/runtime/entrypoint.py Parses file.py:symbol, validates files, imports the user module, and resolves dotted symbols.
src/agenttelemetry/runtime/worker.py Runs inside the child process, invokes the graph, and emits JSON containing graph output and detected tool-attempt lists.
src/agenttelemetry/runtime/isolated.py Owns subprocess execution, timeout handling, safe environment construction, child output parsing, and exit-code mapping.
src/agenttelemetry/cli.py Adds observe with --input, --out-dir, --timeout-seconds, and --allow-live-tools.
tests/test_entrypoint.py Covers parser success, missing separator, missing file, and missing symbol handling.
tests/integration/test_isolated_runner.py Covers safe fixture execution, subprocess timeout, invalid entrypoint exit behavior, and manifest live-tool flags.

Runtime Flow

agenttelemetry observe file.py:graph --input input.json --out-dir runs/test-run
  -> parse entrypoint
  -> create RunManifest
  -> spawn python -m agenttelemetry.runtime.worker
  -> send {"entrypoint": "...", "input": {...}} over stdin
  -> worker imports graph and calls graph.invoke(input)
  -> parent enforces timeout and captures JSON output
  -> write runs/test-run/manifest.json
  -> write runs/test-run/output.json on success
